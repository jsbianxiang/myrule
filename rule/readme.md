# 个人自用规则集

## 概述

个人维护的网络代理规则集，用于优化网络访问体验。**请勿直接引用**，规则会根据个人需求随时调整。

## 规则分类

### 地区域名规则

- **香港域名** - 香港地区相关域名
- **台湾域名** - 台湾地区相关域名  
- **日本域名** - 日本地区相关域名
- **韩国域名** - 韩国地区相关域名
- **美国域名** - 美国地区相关域名

### 代理规则

- **代理域名** - 通用代理域名
- **直连域名** - 直连访问域名

## 使用说明

1. 根据需要选择相应的规则文件
2. 导入到你的代理工具中（如 Clash、mihomo 等）
3. 定期更新规则以保持最佳效果

## 注意事项

- 本规则集仅适用于个人使用场景
- 规则会根据实际使用需求进行调整
- 请勿在生产环境中直接使用
- 建议根据自身网络环境进行适当修改

## 更新日志
规则会不定期更新，主要基于：
- 网络环境变化
- 个人使用需求调整
- 域名解析变更
